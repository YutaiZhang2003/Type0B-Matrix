# Unused Human-note computation archive

Nothing under this directory is imported by the certified q-expansion,
Yuchen's branching grid, or the active PBW verification tests.

* `legacy_direct_chi_anchor/` preserves the superseded standalone
  `DirectHalfNSAnchor` experiment and its old assembler/tests.
* `pbw_c_recursion_double_virasoro_crosscheck/` preserves broader exploratory
  checks that are not part of the current NS--R--R certification route.

These files are retained for provenance only. They must not be used as a
second implementation of the current Human-note boundary data without a new
derivation and certification.
