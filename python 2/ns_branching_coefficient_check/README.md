# NS branching-state converter

`check_ns_branch_norms.py` reconstructs the missing local NS free-field layer
used by the NS–R–R branching evaluators.

The module expands the finite string

```text
chi_r = f_r - i theta_r
```

into auxiliary-fermion and physical-fermion paths.  It then transports each
physical endpoint from the Heisenberg/fermion Fock basis to the abstract
NS super-Virasoro PBW basis.  The transition direction is

```text
PBW coefficients -> free-field Fock coefficients.
```

Consequently, endpoint conversion uses the inverse transition matrix.
`abstract_eta_coefficients` is the historical symbolic interface.
`abstract_eta_coefficients_at` substitutes exact `Q` and `P` values before
inversion and is used by the production three-point grid.

The name `eta` in this compatibility API means the physical free-field
fermion called `theta` in the implementation.  It is not the NS–R–R chiral
structure sign `eta` used by the three-point evaluator.

Run the self-audit through the stored grid level with

```bash
python3 "python 2/ns_branching_coefficient_check/check_ns_branch_norms.py"
```

The module also exposes `abstract_gram` and `branch_norm` for direct NS
Shapovalov-norm checks.

Low normalized double-Virasoro primaries are listed in
`LOW_NS_DOUBLE_VIRASORO_PRIMARIES.md` and generated by
`enumerate_double_virasoro_primaries.py`.
