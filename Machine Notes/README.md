# Reading the block notes

For the **complete current algorithm**, read
arbitrary_plumbing_superconformal_blocks.tex and its included
superconformal_block_conventions_appendix.tex and
genus_two_partition_function_test_appendix.tex. These now use the
BPZ inversion \(1/z\), the \(-i/z\) first-slot spin lift, the
\(-i\sqrt q/z\) edge lift, graded BPZ transpose, current ground
metrics and Ward identities, full tensor sewing, current convolution,
and split-edge insertion. AGENTS.md in the repository root is the
short operational summary. The independent derivation is
bpz_one_over_z_sewing_2026-09-25.tex.

The separate ramond_blocks_current_algorithm.tex retains the
branching, CCY, truncation, and caching performance record but
still displays the preceding theta-frame signs. The dated test
tables in the complete note are explicitly labeled historical
where they were not rerun under the current convention. Do not
quote their runtimes as new-convention measurements.

conventions.md is the BRY Type 0B amplitude and matrix-model
normalization ledger. Its physical amplitude conventions are separate
from the chiral BPZ choice here. In particular, any BRY-to-block
three-point conversion must be checked in the current BPZ frame before
it is used.

The manuscripts in draft/ and draft-long/ are author-controlled;
the current long paper is draft-long/scblock_long.tex. Do not edit
either manuscript without explicit authorization from the user.
